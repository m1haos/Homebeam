# Homebeam

Дома для Paper, над которыми стоят световые столбы. Столб дома видит только его владелец и друзья, которых он пригласил. Если дом далеко, столб показывается на горизонте в его сторону и подписан расстоянием.

## Возможности

- `/home set <имя>` ставит дом там, где вы стоите. Имя может быть русским и с пробелами: `/home set Дом у реки`.
- Над каждым домом стоит стеклянная призма высотой 64 блока. Она медленно вращается, «дышит» по ширине и обведена свечением своего цвета, которое видно сквозь землю. Новый столб вырастает из земли примерно за секунду.
- Рядом со столбом висит подпись с именем дома и расстоянием до него. Чем дальше дом, тем крупнее подпись: размер растёт с расстоянием до предела из конфига.
- Дом дальше 64 блоков рисуется на кольце вокруг игрока, в сторону дома. Подпись показывает настоящее расстояние: `1,2 км`. Когда вы подходите ближе, столб встаёт на сам дом.
- Столбы и подписи — сущности, которые сервер показывает только нужному игроку. Другие игроки их не видят, а в мире они не сохраняются.
- `/home <имя>` — телепорт с разгоном: вокруг игрока поднимается спираль цвета дома, в строке над хотбаром заполняется полоска, с каждой секундой звук звучит выше. Если сдвинуться с места или получить урон, телепорт отменится. На месте прибытия столб дома вспыхивает.
- `/home invite <игрок> <дом>` показывает дом другу. В его подписи видна голова владельца, а отправиться туда можно командой `/home tp Ника:База`.
- После смерти над местом гибели встаёт красный столб с таймером. Он гаснет, когда вы возвращаетесь, или через 10 минут.
- 8 цветов в комплекте, новые дома берут их по очереди. `/home color <цвет> <дом>` меняет цвет. Свои цвета добавляются в `config.yml`: блок призмы и цвет в `#RRGGBB`.
- `/home show <дом>` оставляет один столб, остальные прячутся. `/home hide` прячет все, `/home show` возвращает.
- Каждая система выключается в `modules:`, у команды и всех подкоманд есть алиасы из конфига. Частицы и звуки телепорта настраиваются там же.

## Установка

1. Положите `Homebeam-1.0.0.jar` в `plugins/` и запустите сервер.
2. Встаньте на место и напишите `/home set База`.
3. Отойдите подальше и обернитесь.

## Команды

Основная команда — `/homebeam`, алиасы по умолчанию: `/home`, `/homes`, `/hb`.

| Команда | Алиасы | Что делает |
|---|---|---|
| `/home <дом>` | | телепорт, короткая форма |
| `/home tp <дом>` | `go`, `warp` | телепорт; к дому друга — `<владелец>:<дом>` |
| `/home set <имя>` | `add`, `create`, `sethome` | поставить дом или перенести существующий |
| `/home delete <дом>` | `del`, `remove`, `rm` | удалить дом |
| `/home rename "<дом>" <новое имя>` | `mv` | переименовать; старое имя в кавычках, если в нём пробелы или русские буквы |
| `/home color <цвет> <дом>` | `colour`, `paint` | цвет столба |
| `/home list` | `ls` | ваши дома и дома друзей, по имени можно кликнуть |
| `/home invite <игрок> <дом>` | `share`, `trust` | показать дом другу |
| `/home uninvite <игрок> <дом>` | `unshare`, `untrust` | убрать друга из гостей |
| `/home show [дом]` | `on` | показать все столбы или только один |
| `/home hide` | `off` | спрятать столбы |
| `/home reload` | `rl` | перечитать конфиг и тексты |
| `/home help` | `?`, `h` | список команд |

## Права

| Право | По умолчанию | Что даёт |
|---|---|---|
| `homebeam.use` | все | все команды игрока и столб на месте гибели |
| `homebeam.admin` | op | всё, включая `reload` и дома без ограничения |
| `homebeam.limit.<число>` | — | сколько домов можно поставить; из нескольких берётся наибольшее, без права — `homes.default-limit` (3) |
| `homebeam.limit.unlimited` | — | без ограничения |
| `homebeam.bypass.warmup` | — | телепорт без разгона |
| `homebeam.bypass.cooldown` | — | телепорт без перезарядки |
| `homebeam.command.<подкоманда>` | как у `use` | доступ к одной подкоманде |

Права обхода не входят в `homebeam.admin`, чтобы администратор видел эффект телепорта так же, как игроки.

## Файлы

| Файл | Что в нём |
|---|---|
| `config.yml` | язык, модули, алиасы, лимиты, телепорт, размеры столбов, цвета, частицы, звуки |
| `lang/ru.yml`, `lang/en.yml` | все тексты, включая шаблоны подписей над столбами |
| `homes.yml` | дома игроков, сохраняется сразу после каждого изменения |

## Совместимость

Paper 26.2, Java 25. Головы в подписях требуют клиент 1.21.9 или новее. `beams.anchor-distance` должно быть меньше дальности прорисовки сервера в блоках и дальности отслеживания display-сущностей в `spigot.yml` (128 по умолчанию), иначе столбы рядом с краем будут пропадать. Планировщик работает через планировщик игрока, но на Folia плагин не проверялся, поэтому `folia-supported` не включён.
